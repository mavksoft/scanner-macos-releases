# Changelog — Net-Analyzer Scanner for macOS

All notable releases published in this repository.

## v1.3.1 — 2026-10-05

Ventana principal al 96% (margen 2%), columnas dimensionadas al contenido real (IPv6, MAC, cabecera de seguridad localizada), panel de detalle más ancho, propagación fiable del modo claro/oscuro/sistema a todas las ventanas, y emergente explicativo al activar la monitorización continua.

**Assets:** `Scanner-Net-Analyzer-1.3.1.dmg` · `Scanner-Net-Analyzer-1.3.1.zip`

## v1.3.0 — 2026-10-04

Auditoría de router multi-marca: extractores propios para 11 fabricantes (Livebox, HGU, TP-Link, FRITZ!Box, MikroTik, Huawei, ASUS, Netgear, D-Link, Sercomm/Vodafone, Linksys) + scrape genérico post-login; interfaces UniFi separadas (SSID+AP+banda / switch+puerto); panel web embebido funcional con cert autofirmado.

**Assets:** `Scanner-Net-Analyzer-1.3.0.dmg` · `Scanner-Net-Analyzer-1.3.0.zip`
